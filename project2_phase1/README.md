# Project 2 — Phase 1

A static learning showcase covering LangChain and LangGraph fundamentals for the DevSynt AI Automation Internship.

## How to run

Open `index.html` in any modern web browser.

No server or package installation is required.

## What I learned

This week helped me understand how LangChain organizes common LLM application components such as prompts, chains, and output parsers. I also learned how LangGraph uses nodes, edges, state, and conditional paths for workflows where the next step can change.

I also learned the basic idea of tool calling, conversation memory, and orchestrator agents. The orchestrator pattern is especially important because it will be used in the upcoming project to route work to specialized agents.
